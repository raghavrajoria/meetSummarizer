# Hosted ASR contract v1
`ASR_MODE=remote`, `ASR_SERVICE_URL` is the full HTTPS POST endpoint (for example `/transcribe`); no model location is assumed. The host must implement diarization when turns are omitted. It returns speaker-attributed canonical segments, not raw Whisper results.

Request: multipart/form-data; `audio` binary 16 kHz mono PCM WAV; optional `turns` JSON string array of `{start:number,end:number,speaker:string}` in recording-relative seconds. `Authorization: Bearer <ASR_SERVICE_TOKEN>`; host rejects missing/wrong credentials with 401. Maximum 512 MB and two hours; host returns 413 above either limit. Reject undecodable audio with 415, invalid turns with 422. Bounds: finite nonnegative start <= end <= duration. Host may cap lower limits but must communicate them before deployment. Timeout default 120 seconds (`ASR_SERVICE_TIMEOUT_SECONDS`); increase for long synchronous jobs; client retries through the explicit failed-job retry endpoint, never silently double-processes.

200: JSON array of canonical segments defined in AGENTS section 5. Required fields: segment_id,start,end,speaker,speaker_name,language,text_native,text_roman,text_english,quality,reasons,asr. Enrichment may be null. `asr` contains method, whisper_lang, optional whisper_lang_conf, mms_lang, optional mms_lang_conf; transcription confidence optional. IDs hash rounded millisecond start/speaker; collisions use the adapter discriminator. `ur` routes to `hi` retaining raw ASR metadata. Empty audio returns []. Rejected segments remain in output for review but never reach LLM. 429 includes Retry-After; 503 model unavailable; other errors `{detail: string}` with no audio/transcript/token in logs.

The client also accepts legacy stored ASR via a separate import adapter. New service responses must be canonical. Fake-server tests run offline. Configure the service URL and token on API/worker, keep the GPU service out of these containers.

Owner-approved language extension (2026-10-05): mul=mixed and und=unknown are valid only with quality=review. Preserve legacy label in asr.source_language. ISO 639-1 list is frozen from the Library of Congress table https://www.loc.gov/standards/iso639-2/ISO-639-2_utf-8.txt. Unknown labels never become silently accepted English/Hindi.

Source-rejected unresolved imports keep asr.source_quality=rejected and remain blocked from all LLM paths even with relaxed review.
